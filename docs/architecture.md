# Архитектура

Источник истины — файлы ревизии, не база редактора. Один и тот же каталог при тех же байтах даёт тот же Markdown справочника. Пользовательский Python не импортируется. Команды сборки из yaml не запускаются.

```
источник (local_path или git clone)
        │
        ▼
   API (FastAPI) ── очередь в SQLite
        │
        ▼
   worker
        │  config → extract → weave → HTML
        ▼
   /publish/{проект}/{версия}/
        │
        ▼
   nginx :8080  →  /sites/…, /health, /api, /hooks
```

## Сервисы Compose

| Сервис | Процесс | Роль |
| --- | --- | --- |
| `api` | `docloom serve` | Проекты, постановка билдов, webhook, `/health` |
| `worker` | `docloom worker` | Забирает очередь и пишет книгу на диск |
| `nginx` | nginx 1.27 | Раздаёт опубликованные сайты и проксирует API |
| `test` | `pytest` | Профиль `test`, в обычный `up` не входит |

Redis в MVP нет. Очередь и метаданные — файл `docloom.sqlite` на томе `data`.

Процесс `docloom` в контейнере работает от uid 10001. Точка входа при старте от root только создаёт каталоги томов и отдаёт управление этому пользователю.

## Тома

| Том | Путь в контейнере | Содержимое |
| --- | --- | --- |
| `data` | `/data` | SQLite, логи билдов, heartbeat worker |
| `publish` | `/publish` | Готовый HTML, его же читает nginx |
| `sources` | `/sources` | Клоны, если у проекта задан `git_url` |

Образ дополнительно содержит `/opt/docloom/samples` — каталог демо только для чтения. `local_path` принимается, если после `resolve` он лежит внутри одного из корней `DOCLOOM_SOURCE_ROOTS`. В compose это `/opt/docloom/samples` и `/sources`.

## Пара (проект, версия)

Worker не берёт второй билд, пока для той же пары есть статус `running`. Другая версия того же проекта может собираться одновременно. Имя версии получается из `ref`: префиксы `refs/heads/` и `refs/tags/` снимаются, пустое имя и `HEAD` становятся `latest`. В имени допустимы буквы, цифры, точка, подчёркивание и дефис, не длиннее 100 символов. Слэш в имени версии не принимается.

## Сеть

Снаружи открыт только порт `8080`. API слушает `8000` внутри сети compose. Nginx резолвит имя `api` через DNS Docker (`127.0.0.11`) на каждый запрос, поэтому пересоздание контейнера API не оставляет прокси со старым IP.

Статика `/sites/` не проксируется в API: nginx читает том `publish` напрямую.
