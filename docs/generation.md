# Генерация

Сборка одного источника идёт в фиксированном порядке.

1. Читается `docloom.yml`.
2. Гайды: `SUMMARY.md`, затем Markdown из каталога `sources.guides`.
3. Python: обход `*.py` под каждым корнем из `sources.python`, разбор `ast`.
4. OpenAPI 3: по странице на каждую операцию.
5. Если есть предупреждения — страница диагностики.
6. Склейка `SUMMARY`: руководства, справочник Python (без методов: они ссылаются со страницы класса), справочник HTTP, служебное.

Повторный прогон на тех же файлах даёт тот же Markdown. В текст страниц не подставляется время сборки.

## Python

Импорта и исполнения нет. Публичными считаются имена без одного ведущего `_`. Из дандеров в справочник входит только `__init__`. Модуль и каталог, чьё имя начинается с `_`, пропускаются; `__init__.py` остаётся страницей пакета.

Если в модуле есть `__all__` из строковых литералов, в справочник модуля попадают только эти функции и классы. Имена из `__all__`, которых в файле нет, перечисляются как повторный экспорт.

Страница символа содержит сигнатуру, docstring, таблицу параметров (без `self` и `cls`), аннотацию возврата и путь `файл:строка`. Символ без docstring остаётся в книге и получает предупреждение `missing_docstring`. Файл с синтаксической ошибкой не роняет сборку: предупреждение `syntax_error`, остальные файлы обрабатываются.

Имена вроде `__init__` экранируются, чтобы Markdown не превратил их в выделение.

## OpenAPI

Принимается спецификация с полем `openapi`, начинающимся на `3.`. Методы: `get`, `post`, `put`, `patch`, `delete`, `head`, `options`, `trace`. На странице — summary, `operationId`, параметры, тело, ответы с примерами и требования security. Ссылки `$ref` показываются как есть, без полного разворачивания компонентов.

Битый YAML, не объект, версия не 3.x или отсутствие `paths` дают `invalid_openapi`. Операций из этого файла нет, остальные источники собираются.

## Статусы книги

| Статус | Когда |
| --- | --- |
| `success` | Предупреждений нет |
| `success_with_warnings` | Книга собрана, но есть диагностика |
| `failed` | Не прочитан источник: нет `docloom.yml`, путь вне allowlist, git не смог сделать checkout |

Пустой каталог `src/` и сломанный OpenAPI — это `success_with_warnings`, не падение.

## Отпечаток исходника

Для `local_path` в `build.json` пишется SHA-256 содержимого файлов: путь и байты в стабильном порядке, без `.git` и `__pycache__`. Для `git_url` пишется SHA коммита после checkout указанной ветки или тега. Глубина клона — 1. `ref` передаётся аргументом `git`, не через оболочку.
