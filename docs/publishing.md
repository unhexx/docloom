# Публикация

Worker пишет каталог `/publish/{имя проекта}/{версия}/`. Nginx отдаёт его как `/sites/{имя}/{версия}/`.

## Файлы версии

| Файл | Назначение |
| --- | --- |
| `index.html` | Первая страница книги, обычно первый гайд |
| `404.html` | Страница отсутствующего адреса внутри версии |
| `SUMMARY.md` | Уже склеенная навигация |
| `docs/*.html` и `generated/**/*.html` | Страницы |
| рядом с HTML | исходный Markdown страницы |
| `assets/theme.css` | Своя тема, без CDN |
| `assets/pygments.css` | Подсветка кода, светлая и тёмная |
| `assets/search.js` | Клиентский поиск |
| `search-index.json` | Заголовок, заголовки разделов, текст, путь |
| `llms.txt` | Оглавление со ссылками на HTML |
| `llms-full.txt` | Тексты страниц подряд |
| `build.json` | Манифест сборки |

Ссылки на стили и страницы относительные и считаются от файла, в котором лежат. Главная не заимствует префикс вложенной страницы.

## Читатель

Тема не является форком `GitbookIO/gitbook`. На странице:

- шапка с именем проекта, текущей версией, поиском и переключателем темы;
- левое меню по разделам «Руководства», Python, HTTP, «Служебное»;
- текст с подсветкой fenced-блоков;
- правое оглавление страницы;
- ссылки на предыдущую и следующую страницу в порядке сборки.

Тёмная тема включается кнопкой «Тема» и запоминается в `localStorage`. Если записи нет и система просит тёмную схему, тёмная тема ставится сразу. На ширине до 960px боковое меню скрыто за кнопкой «Меню», правого оглавления нет.

Поиск начинается с двух символов, грузит `search-index.json` один раз и показывает до восьми совпадений. Совпадение в заголовке выше совпадения в тексте. Ссылка строится от каталога текущей страницы, поэтому поиск работает и с вложенного URL.

Версия в шапке — имя каталога. Соседние версии, уже лежащие в `versions`, получают ссылку на свой `index.html`. Пока собрана одна версия, в шапке только её имя.

Неизвестный путь под `/sites/{проект}/{версия}/` получает `404.html` этой версии и статус HTTP 404. Ответы `/api/` этот обработчик не подменяет.

## `build.json`

```json
{
  "project": "demo-lib",
  "version": "latest",
  "source_sha": "<отпечаток или git sha>",
  "built_at": "2026-09-24T00:00:00+00:00",
  "status": "success_with_warnings",
  "pages": [{"id": "python:demo_lib.client.Client", "path": "….html", "title": "Client", "kind": "python.class"}],
  "warnings": [{"code": "missing_docstring", "symbol": "demo_lib.util.helper", "file": "src/demo_lib/util.py", "line": 4}],
  "docstring_coverage": {"documented": 6, "missing": 1, "total": 7, "ratio": 0.8571},
  "search_documents": 12,
  "skipped": []
}
```

`skipped` собирает предупреждения чтения: `syntax_error`, `unreadable_file`, `missing_guide`, `missing_openapi`, `invalid_openapi`. Покрытие docstring считается по страницам Python: модуль, класс, функция, метод.

Время `built_at` есть только в манифесте. HTML от него не зависит.
